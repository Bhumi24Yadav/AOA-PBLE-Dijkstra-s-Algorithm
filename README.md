# Campus Shortest Route Finder using Dijkstra's Algorithm

## Project Description

Campus Shortest Route Finder is a menu-driven C program that uses Dijkstra's Algorithm to find the shortest distance and corresponding shortest path from a selected campus location to all other locations.

The campus road network is represented using a weighted adjacency matrix, where locations are vertices and road distances are edge weights.

The program allows users to:

- Enter the campus graph
- Display the adjacency matrix
- Select a source location
- Calculate shortest distances
- Display the corresponding shortest paths

## Algorithm Used

Dijkstra's Algorithm

## Programming Language
 
C

## Data Structure

Weighted Adjacency Matrix
